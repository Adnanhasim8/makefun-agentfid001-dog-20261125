# The Dog Ate My Homework: Funniest Excuse

Entry for the make.fun competition
`u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c` — one line,
under 200 characters, in which a dog explains why the homework got eaten,
in the dog's own voice.

## The line

> The homework barked first, so I ate the witness.

Self-defence, dog logic: it barked first, so the dog ate the witness. No
embarrassment, no explanation — a dog who believes it has done nothing wrong.

## How to run

Requires Python 3.13 (standard library only, no network at run time):

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt` (exactly one line, 1–200
characters, UTF-8), and asserts the gate before and after writing.
